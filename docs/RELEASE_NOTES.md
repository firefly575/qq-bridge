# v0.1.20

两件事：**敏感词过滤可以按会话单独开关**，**人格卡可以按会话分配（多张同时生效）**。

## 1. 敏感词过滤（控制台 → 访问与安全 → 用户权限表）

表格最右侧新增一列「敏感词过滤」：

| 勾选状态 | 行为 |
|---|---|
| 勾选 | 过滤（非管理员默认） |
| 取消勾选 | 该会话**不过滤**：成人/敏感话题、脏话、链接与外部地址、本机路径、凭据样式文本都放行 |

- 管理员那一行默认**不勾选**（即不过滤），也可以手动勾上
- 存 `state/permissions.json` 的 `users[key].sensitive`
- 未设置时：管理员 `false`（不过滤）、其他人 `true`（过滤）

实测：

```
其他人（默认）        → 403 消息含敏感信息，已阻止发送
关掉该会话的过滤后    → 200 放行
owner（默认）         → 200 放行
```

## 2. 按会话分配人格（控制台 → 人格与角色）

新增卡片「按会话分配人格（可同时使用多张人格卡）」：

- **默认人格**：没单独指定的人都用它；选「（不使用人格卡）」则跟随旧的全局角色
- **表格**：每个私聊/群一行，下拉可选任意人格卡
  - 「跟随默认」= 用默认那张
  - 「（不使用人格卡）」= 这个会话跑纯 agent，不注入人格
- 支持**不同用户用不同人格卡同时生效**
- 存 `state/role-assignments.json`；API：`GET/POST /api/role-assignments`

注入点全部改为按会话取人格：`buildWakePromptV2` 的【当前角色】行、旧 chat 模式的角色注入、本地模型回复路径。

实测：

```
GET  /api/role-assignments → 角色卡 ["傲娇助手","小鲸鱼","猫娘"] ｜ 会话 8 个
POST 默认=傲娇助手，private:3964835308=小鲸鱼
读回：assigned=小鲸鱼，effective=小鲸鱼   ✅
```

（角色卡列表已排除 `roles/README.md`，它只是说明文件。）

## 说明

- 人格分配只影响**提示词注入**，不改 DSH 会话本身；同一个会话改了人格后，历史上下文仍在，只是新回合用新卡。
- 敏感过滤关闭后，桥接不再拦截对应会话的出站文本；**日志里的脱敏仍然保留**（日志不写明文凭据）。
